# 社区宠物到家需求确认

本仓库用于两社区宠物到家服务试点的需求确认，供项目负责人、综合体运营方、社区合作方、目标居民和拟聘人员讨论与填写。当前为需求草案和模拟原型，推荐方案尚待确认。

## 填写问卷

**[打开需求确认问卷 V0.2](doc/04_社区宠物到家_需求确认问卷_Grill-me_V0.2.md)**

问卷包含 52 道基础调查题及 30 道 Grill-me 决策问题。每道决策问题提供推荐答案、场景追问、前置依赖和范围或排期影响。

1. 项目负责人先填写附录 A；两个社区分别填写附录 B。
2. 目标居民填写附录 C；实际拟聘人员填写附录 D。
3. 负责人从 G01 至 G05 开始逐轮确认；后续仅讨论前置条件已确认的问题。
4. 按题号记录答案、修改意见、决策人和依据，再回传给项目负责人汇总。

GitHub 页面用于阅读，勾选不会保存为正式答复。需要填写时，可下载或复制问卷到自己的文档，按题号回答后通过约定渠道回传。公开仓库中不要提交真实住宅地址、门锁密码、身份证、电话或详细病历；联系信息和受限材料另行收集。
