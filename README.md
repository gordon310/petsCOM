# 社区宠物到家需求确认

本仓库用于两社区宠物到家服务试点的需求确认，本次问卷由平台运营方填写，由其汇总社区、居民和人员的已知情况。当前为需求草案和模拟原型，推荐方案尚待确认。

## 已确认试点条件

- 试点所在地：中国杭州。
- 试点对象：两个生活居民社区。

平台方补充具体社区名称、合作进度及场地条件，不再选择国家/城市和社区类型。

## 填写问卷

**[打开在线填写问卷](https://gordon310.github.io/petsCOM/)**

[平台运营方问卷文档 V0.3](doc/05_社区宠物到家_平台运营方需求确认问卷_Grill-me_V0.3.md) 用于查看完整说明和决策树。

问卷包含 23 道待答平台基础确认题及 30 道 Grill-me 决策问题。每道决策问题提供推荐答案、场景追问、前置依赖和范围或排期影响。

1. 平台运营方先填写 A24 经营主体及 A02 至 A23 的服务、人力、支付与系统现状。
2. 平台业务负责人从 G01 至 G05 开始逐轮确认；后续仅讨论前置已确认的问题。
3. 社区、居民和人员的相关信息由平台方提供已有证据；未掌握时注明待核实、跟进人及日期。
4. 在填写页勾选答案并补充参数、理由和决策人，点击「导出答复文件」或「复制答复文字」，再回传给问卷发起人汇总。

在线填写页会自动保存草稿到当前浏览器；答案不会上传到公开仓库，也不会自动提交给负责人。换设备或清除浏览数据不会同步草稿，请及时导出备份。GitHub 文档页仍为只读参考，请使用上方在线填写入口。

公开仓库中不要提交真实住宅地址、门锁密码、身份证、电话或详细病历；联系信息和受限材料另行收集。

## 填写页维护

填写页采用无外部依赖的 HTML、CSS 和 JavaScript。题目来源为问卷 Markdown，修改题目后运行 `python3 scripts/build-questionnaire.py` 更新 `questionnaire.json`，再运行 `node --check app.js` 检查脚本语法。GitHub Pages 从 `main` 分支根目录发布。
