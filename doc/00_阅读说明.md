# 社区宠物到家服务平台｜资料阅读说明

当前阶段：运营问卷已回收，四端 UI V1.0 供业务确认，尚未业务验收。

1. **[打开四端可交互原型](https://gordon310.github.io/petsCOM/prototype/)**：用户端与接单小哥为小程序布局，服务站点与总部为 PC 布局，共 50 页。
2. 阅读 [UI V1.0 确认稿](08_社区宠物到家_四端UI原型确认稿_V1.0.md)：包含页面清单、评审路径、38 题追溯、权限与待确认事项。
3. [集中答卷记录与 CSV](https://gordon310.github.io/petsCOM/records.html)：正式答卷为主要需求依据，测试答卷不参与判断。原问卷仍可[在线填写](https://gordon310.github.io/petsCOM/)，多人提交和修订分别留档。
4. V0.1 PRD、信息架构与低保真原型保留历史参考；与正式答卷冲突的流程以 V1.0 确认稿说明为准。

试点确定为中国杭州的两个生活居民社区。真实社区名、场地、时段和负责人仍待补充。

四端原型全部使用演示资料，不执行真实付款、影像、定位、通知或退款。进度与评审意见只在当前浏览器保存；“导出本机评审意见”用于下载回传，不能当成线上已提交。勿填写真实住址、门锁密码或其他敏感资料。
