# 社区宠物到家需求确认

本仓库用于两社区宠物到家服务试点的需求确认，供项目负责人、综合体运营方、社区合作方、目标居民和拟聘人员讨论与填写。当前为需求草案和模拟原型，推荐方案尚待确认。

## 填写问卷

**[打开在线填写问卷](https://gordon310.github.io/petsCOM/)**

[需求确认问卷文档 V0.2](doc/04_社区宠物到家_需求确认问卷_Grill-me_V0.2.md) 用于查看完整说明和决策树。

问卷包含 52 道基础调查题及 30 道 Grill-me 决策问题。每道决策问题提供推荐答案、场景追问、前置依赖和范围或排期影响。

1. 项目负责人先填写附录 A；两个社区分别填写附录 B。
2. 目标居民填写附录 C；实际拟聘人员填写附录 D。
3. 负责人从 G01 至 G05 开始逐轮确认；后续仅讨论前置条件已确认的问题。
4. 在填写页勾选答案并补充参数、理由和决策人，点击「导出答复文件」或「复制答复文字」，再回传给项目负责人汇总。

在线填写页会自动保存草稿到当前浏览器；答案不会上传到公开仓库，也不会自动提交给负责人。换设备或清除浏览数据不会同步草稿，请及时导出备份。GitHub 文档页仍为只读参考，请使用上方在线填写入口。

公开仓库中不要提交真实住宅地址、门锁密码、身份证、电话或详细病历；联系信息和受限材料另行收集。

## 填写页维护

填写页采用无外部依赖的 HTML、CSS 和 JavaScript。题目来源为问卷 Markdown，修改题目后运行 `python3 scripts/build-questionnaire.py` 更新 `questionnaire.json`，再运行 `node --check app.js` 检查脚本语法。GitHub Pages 从 `main` 分支根目录发布。
